# دعوة زفاف مع الأغنية الجديدة

هذا مشروع Railway جاهز للنشر. يحتوي `index.html` على التصميم والموسيقى الجديدة مدمجين داخل ملف واحد؛ لذلك لا تحتاج إلى رفع MP3 منفصل.

## النشر

1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. من Railway اختر New Project ثم Deploy from GitHub Repo.
3. حدّد المستودع، وانتظر انتهاء النشر.
4. من إعدادات Networking اختر Generate Domain.

تبدأ الأغنية عند الضغط على «افتح الدعوة»؛ لأن المتصفحات قد تمنع التشغيل دون تفاعل المستخدم.
تستمر الموسيقى قرابة 39 ثانية، وتظل الصفحة الثانية ظاهرة بعد انتهاء حركة الـ20 ثانية.

لا تنشر مقطعًا صوتيًا محميًا بحقوق النشر دون إذن مناسب.
