# دعوة الزفاف — Railway

المشروع يحتوي على `index.html` مع الأغنية المدمجة، و`server.js` لتشغيل الموقع دون أي مكتبات إضافية.

1. فك ضغط الملف، ثم ارفع الملفات الثلاثة إلى مستودع جديد على GitHub.
2. في Railway اختر New Project ثم Deploy from GitHub Repo واختر المستودع.
3. سيتعرّف Railway على Node.js ويشغّل `npm start`.
4. من إعدادات المشروع: Networking → Generate Domain لإنشاء الرابط العام.
5. يمكن فتح الدعوة عبر الرابط. ستبدأ الأغنية بعد الضغط على «افتح الدعوة» بسبب قيود التشغيل التلقائي على الهواتف.

المشهدان المتحركان 20 ثانية، وبعد ذلك يبقى المشهد الأخير على الشاشة حتى تنتهي الموسيقى (26.6 ثانية).

لإجراء تعديلات على الدعوة لاحقًا، استخدم ملف «دعوة_الزفاف_للتعديل_مع_الموسيقى.html» المنفصل وصدّر دعوة الضيوف المحدثة ثم استبدل بها `index.html` في المستودع.

**حقوق النشر:** تأكّد من امتلاك إذن نشر الأغنية على موقع عام.
